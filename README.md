# 🔐 Password Strength Checker with Secure Login & OTP Verification

A cybersecurity-based web application designed to analyze password strength, encourage secure password creation, and provide user authentication through signup, login, and OTP verification.

## 🚀 Project Overview

The Password Strength Checker helps users understand how secure their passwords are. It evaluates passwords in real time and provides feedback based on different security conditions.

## ✨ Features

- User Signup and Login
- Phone Number Authentication
- OTP Verification
- Real-Time Password Strength Analysis
- Weak, Medium and Strong Password Classification
- Password Generator
- Password Improvement Suggestions
- Password Strength Graph
- Login History
- User Dashboard

## 🛠️ Technologies Used

- HTML5 – Webpage Structure
- CSS3 – Styling and User Interface
- JavaScript – Functionality and Validation
- Chart.js – Graphical Password Analysis (if used in your implementation)
